# Smart Invoice

Smart Invoice は、請求書の作成から管理、PDF 出力までをシンプルに行えるデスクトップアプリです。顧客情報と明細を入力すると、消費税と合計金額を自動計算し、印影入りの A4 請求書を発行できます。

データは外部サーバーへ送信せず、アプリを使用している PC のローカルストレージに保存されます。個人事業主や小規模事業者が、手軽に請求書を作成・管理する用途を想定しています。

## 主な機能

- 請求書の作成、下書き保存、発行履歴の管理
- 顧客情報と事業者情報の登録
- 8%・10%・非課税に対応した消費税の自動計算
- 請求書番号、発行日、支払期限、振込先、備考の設定
- 代表者名からの印影生成、または画像による印影登録
- A4 請求書のプレビューと PDF 出力
- 発行件数、下書き件数、当月請求額の確認
- PC 内へのローカルデータ保存

> [!NOTE]
> 電子印影は請求書上の表示用です。電子署名や本人認証の機能はありません。

## 技術構成

- Tauri 2
- React 19
- TypeScript
- Vite
- html2canvas / jsPDF

## 開発環境での起動

事前に Node.js、Rust、および Tauri の開発に必要な依存関係を用意してください。

```sh
npm install
npm run tauri dev
```

Web UI のみを起動する場合は、次のコマンドを使用します。

```sh
npm run dev
```

## ビルド

デスクトップアプリのインストーラーを作成します。

```sh
npm run tauri build
```

フロントエンドのみをビルドする場合は、次のコマンドを使用します。

```sh
npm run build
```
